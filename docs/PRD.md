# FitLog 个人健身记录 — MVP PRD

> 版本 v0.1 | 2026-11-03 | 单用户 · 本地优先 · 移动端优先 Web/PWA · 单位 kg/cm

## 1. 产品定位

个人健身记录软件：记录每天训练、饮食宏量、体重与身体维度，自动统计训练容量、力量水平（e1RM/PR）、营养达成率与身体变化趋势，帮助长期看到进步。

**形态决策**：选择响应式 Web/PWA，理由：
- 无需安装审核，手机浏览器即用，迭代最快；
- IndexedDB 支持离线存储与"添加到主屏"；
- 后续可低成本增加云同步与后端。

## 2. 用户与约束

- 用户：单人使用，无登录（数据模型预留 `userId` 字段，便于未来多用户/云同步）。
- 存储：纯本地（IndexedDB），不上传任何数据。
- 单位：重量 kg（输入支持 0.25kg 步进微调）、长度 cm、能量 kcal、营养素 g。
- 日期：全部使用本地时区的日历日期（`YYYY-MM-DD`）。
- 食物营养数据一律手动输入，不内置、不编造营养数据库。

## 3. 功能范围

### P0（MVP，本次交付 — 精简闭环）
| 模块 | 功能 |
|---|---|
| 训练录入 | 按日期创建训练，填部位/备注；添加动作（库选或录入时直接自定义），每组录重量/次数/RPE(可选)；增删改组 |
| 训练统计 | 自动计算每次训练总容量 Σ(重量×次数)、总组数、总次数、各动作容量 |
| 力量趋势 | 动作详情页：该动作全部记录、e1RM（Epley）趋势、最大重量、PR 列表 |
| 饮食录入 | 按早/中/晚/加餐录食物：名称、份量、热量、碳水、蛋白质、脂肪 |
| 饮食汇总 | 每日总热量/碳水/蛋白/脂肪；营养目标内联设置；剩余量与达成率 |
| 身体数据 | 体重（可选体脂率）；维度：胸/腰/臀/臂/腿 |
| 趋势图 | 体重 7 日移动平均；动作 e1RM 趋势 |
| 数据导出 | 训练、饮食、身体数据三类 CSV 导出（UTF-8 BOM，Excel 可直接打开） |

### P1（后续迭代）
统计报表页（周训练统计、肌群容量分布、营养趋势图）、今日概览页、维度趋势图与自定义部位、训练模板、常用食物、PR 提醒、周报页、数据导入、lb 显示切换、动作库管理页。

### P2（暂不做）
大食物库、AI 估算、社交、课程。

## 4. 页面清单与导航

移动端底部 Tab 导航（3 个）：**训练 · 饮食 · 身体**；设置入口在各页顶部。

| 页面 | 路由 | 内容 |
|---|---|---|
| 训练列表 | `/workouts` | 按日期倒序的训练卡片（容量/组数摘要），新建训练 |
| 训练编辑 | `/workouts/:id` | 部位/备注 + 动作分组录入（组行：重量、次数、RPE），实时容量汇总 |
| 动作历史与力量趋势 | `/exercises/:id` | 该动作全部组记录、e1RM 趋势图、最大重量、PR 列表 |
| 饮食记录 | `/diet` | 日期切换 + 四餐分组录入，当日宏量汇总条与达成率（目标内联设置） |
| 身体数据 | `/body` | 体重/体脂录入、维度录入，体重 7 日移动平均趋势图 |
| 设置 | `/settings` | 动作库查看、CSV 导出、清空数据 |

## 5. 关键用户流程

**录一次训练**：训练 Tab → 新建（默认今天）→ 填部位 → 添加动作（库选/自定义）→ 逐组输入重量/次数（RPE 可选）→ 页面底部实时显示总容量/组数/次数 → 保存。

**录一天饮食**：饮食 Tab → 选餐次 → 输入食物名/份量/宏量 → 保存 → 顶部汇总条实时更新（摄入 vs 目标 vs 剩余）。

**看力量进步**：报表 Tab → PR 列表，或训练记录 → 某动作 → e1RM 趋势图 + 历史 PR。

## 6. 验收标准（对应 P0）

1. 完整录入一次训练，正确显示总容量、总组数、总次数、各动作容量与动作 e1RM；
2. 录入一天多餐饮食，正确汇总热量与碳水/蛋白/脂肪，并对照目标显示达成率；
3. 记录体重与维度，显示趋势图（体重含 7 日移动平均）；
4. 查看某动作的力量趋势与 PR 列表；
5. 一键导出训练/饮食/身体三类 CSV；
6. 手机浏览器（375px 宽度基准）完整可用，桌面端居中自适应。
